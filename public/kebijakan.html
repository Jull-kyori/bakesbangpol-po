Aturan Komentar & Privasi

Informasi ini menjelaskan tata cara komentar publik pada situs.

Aturan komentar

  • Gunakan nama tampilan yang pantas. Komentar tidak memerlukan akun.
  • Sampaikan pendapat dengan sopan dan tetap pada topik berita.
  • Dilarang mengirim spam, ancaman, ujaran kebencian, pelecehan, konten melanggar hukum, atau informasi pribadi.
  • Komentar dan balasan ditinjau admin sebelum ditampilkan. Admin dapat menolak atau menghapus komentar yang melanggar aturan.
  • Pengunjung dapat melaporkan komentar melalui tombol “Laporkan”. Laporan ditinjau oleh admin.
  • Kolom komentar bukan kanal pengaduan resmi. Gunakan panduan aspirasi dan pengaduan untuk memilih kanal yang sesuai.

Informasi yang disimpan

  • Nama tampilan dan isi komentar atau balasan yang dikirim.
  • Reaksi suka/tidak suka dan laporan komentar, termasuk alasan serta keterangan yang Anda masukkan.
  • Cookie acak pada browser digunakan untuk mengingat reaksi dan mencegah laporan berulang. Situs menyimpan nilai hash cookie untuk fungsi tersebut, bukan token cookie mentah.
  • Alamat IP dipakai sementara di memori server untuk membatasi kiriman berlebihan; fitur komentar ini tidak menyimpan alamat IP ke data komentar.
  • Nama tampilan terakhir dapat disimpan di penyimpanan lokal browser agar formulir lebih mudah digunakan. Anda dapat menghapus data situs melalui pengaturan browser.
  • Untuk menghitung statistik kunjungan halaman, situs menyimpan ID acak pihak pertama di penyimpanan lokal browser (ID diperbarui setelah 180 hari) dan mencatat halaman serta waktu kunjungan. ID ini bukan identitas orang; statistik pengunjung unik hanya perkiraan dan dapat terhitung ulang saat Anda berganti browser atau menghapus data situs. Situs tidak menyimpan alamat IP, informasi perangkat, atau kata pencarian sebagai bagian dari statistik trafik; alamat IP dipakai sementara di memori untuk membatasi kiriman kunjungan berlebihan. Catatan trafik dan aktivitas admin dihapus setelah 180 hari.

Penggunaan dan penghapusan data

Data komentar, reaksi, dan laporan disimpan pada server pengelola situs untuk menampilkan diskusi, mencegah penyalahgunaan, dan membantu moderasi. Admin dapat melihat komentar dan laporan, menyetujui atau menolak komentar, serta menghapus komentar beserta balasannya. Laporan digunakan untuk peninjauan dan tidak ditampilkan kepada pengunjung lain.

Jangan mengirim informasi rahasia atau data pribadi yang tidak diperlukan. Untuk meminta peninjauan atau penghapusan komentar, hubungi pengelola melalui kanal resmi Bakesbangpol atau Pemerintah Kabupaten Ponorogo.

FAQ situs berisi jawaban tetap yang ditulis untuk informasi Bakesbangpol. Pertanyaan pengunjung tidak dikirim ke layanan AI dan tidak disimpan sebagai riwayat chat. Kebijakan penyedia hosting yang digunakan situs dapat berlaku secara terpisah.

Halaman tertentu juga memuat font, ikon, atau pustaka grafik dari penyedia eksternal seperti Google Fonts, cdnjs, dan jsDelivr. Saat halaman tersebut dibuka, browser Anda dapat menghubungi penyedia terkait dan membagikan alamat IP serta informasi permintaan standar. Sebelum peluncuran resmi, instansi sebaiknya meninjau kebutuhan penggunaan CDN dan kebijakan privasinya atau menyajikan aset tersebut dari server sendiri.

Dengan mengirim komentar, Anda memahami bahwa komentar akan ditinjau sebelum ditampilkan dan wajib mengikuti aturan di halaman ini.
